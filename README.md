# 뚜잇

---

## 서비스 소개

- 일정과 할일을 하나의 앱에서 같이 관리할 수 있습니다.

---

## 사용 기술

- `Kotlin-2.2.21`
- `Compose Multiplatform:1.9.3`, `Room:2.8.0`, `Koin:4.10`, `coroutine:1.10.1`, `firebase-bom:33.10.0 `, `ksp:2.2.21-2.0.4`

---

## 개발 기간

- Android 개발 (2025.02 ~ 2025.07)
- Android + iOS 개발 (2025.08 ~ )
---

## 주요 기능

 - #### 로그인
   
   - 구글 로그인 기능
   - 애플 로그인 기능(iOS)
   - 익명 로그인 기능


 - #### 일정 + 할 일 통합 뷰 

   - 주간 캘린더, 월간 캘린더 변환
   - 캘린더에 날짜별 일정 갯수, 할 일 갯수 표시
   - 주간, 월간 목표 설정 기능
 
 - #### 바탕화면 위젯
